📦 Installation Guide

📱 Termux (Android)

```bash
pkg update && pkg upgrade
pkg install python python-pip git
git clone https://github.com/shahid2005a/PHONE-INFO-.git
cd PHONE-INFO-
pip install flask flask-cors
python main.py
```

⚡ Termux Single Command Install

```bash
pkg update -y && pkg upgrade -y && pkg install python python-pip git -y && git clone https://github.com/shahid2005a/PHONE-INFO-.git && cd PHONE-INFO- && pip install flask flask-cors && python main.py
```

🐧 Linux (Ubuntu/Debian/Kali)

```bash
sudo apt update && sudo apt install python3 python3-pip git -y
git clone https://github.com/shahid2005a/PHONE-INFO-.git
cd PHONE-INFO-
pip3 install flask flask-cors
python3 main.py
```

🍎 macOS

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
brew install python git
git clone https://github.com/shahid2005a/PHONE-INFO-.git
cd PHONE-INFO-
pip3 install flask flask-cors
python3 main.py
```

🔵 Windows (CMD / PowerShell as Admin)

```cmd
git clone https://github.com/shahid2005a/PHONE-INFO-.git
cd PHONE-INFO-
pip install flask flask-cors
python main.py
```

🛠️ Troubleshooting Guide

<p align="center">
  <table border="1">
    <tr>
      <th>Issue</th>
      <th>Solution</th>
      <th>Status</th>
    </tr>
    <tr>

      <td>Install pip: <code>sudo apt install python3-pip</code> / <code>brew install python</code> / <code>pkg install python-pip</code></td>
      <td><img src="https://img.shields.io/badge/✅-Fixed-brightgreen"/></td>
    </tr>
    <tr>
      <td>❌ ModuleNotFoundError: flask</td>
      <td><code>pip3 install flask flask-cors</code></td>
      <td><img src="https://img.shields.io/badge/✅-Fixed-brightgreen"/></td>
    </tr>
    <tr>
      <td>❌ Permission Denied</td>
      <td>Use <code>sudo</code> before python3 or <code>chmod +x script.py</code></td>
      <td><img src="https://img.shields.io/badge/✅-Fixed-brightgreen"/></td>
    </tr>
    <tr>
      <td>❌ Cloudflared not downloading</td>
      <td>Download manually using the table above</td>
      <td><img src="https://img.shields.io/badge/✅-Fixed-brightgreen"/></td>
    </tr>
    <tr>
      <td>❌ Port 3000 already in use</td>
      <td>Auto‑kills old processes. Manual: <code>lsof -i :3000</code> / <code>netstat -ano | findstr :3000</code></td>
      <td><img src="https://img.shields.io/badge/✅-Fixed-brightgreen"/></td>
    </tr>
    <tr>
      <td>❌ GPS not working</td>
      <td>User must click "Allow" on browser's location permission popup</td>
      <td><img src="https://img.shields.io/badge/✅-Fixed-brightgreen"/></td>
    </tr>
    <tr>
      <td>❌ python: command not found</td>
      <td><code>pkg install python</code> or use python3</td>
      <td><img src="https://img.shields.io/badge/✅-Fixed-brightgreen"/></td>
    </tr>
    <tr>
      <td>❌ git: command not found</td>
      <td><code>pkg install git</code> or <code>apt install git</code></td>
